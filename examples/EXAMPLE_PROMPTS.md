# Example Prompts for AgentForge 🚀

Below are example prompts you can use with AgentForge to generate full applications. Simply paste any of these into the prompt input bar on the dashboard.

---

## 🟢 Beginner-Level Projects

### 1. Personal Portfolio Website
```
Build a personal portfolio website with a hero section, about me, skills list,
project showcase cards, and a contact form. Use HTML, CSS, and vanilla JavaScript.
Make it responsive and modern looking with a dark theme.
```

### 2. Todo List Application
```
Create a task management to-do list app with features to add, edit, delete,
and mark tasks as complete. Include priority levels (high, medium, low),
due dates, and local storage persistence. Use Python Flask for the backend
and HTML/CSS/JS for the frontend.
```

### 3. Calculator App
```
Build a scientific calculator web application that supports basic arithmetic,
square root, power, percentage, and memory functions. Include keyboard support
and a clean modern UI. Use HTML, CSS, and JavaScript.
```

---

## 🟡 Intermediate Projects

### 4. URL Shortener Service
```
Build a URL shortener service with a REST API. Features: generate short codes,
redirect short URLs to original URLs, track click counts and analytics per link,
and provide a simple web dashboard to manage links. Use Python FastAPI for the
backend and SQLite for storage.
```

### 5. Real-Time Chat Application
```
Create a real-time chat application with user authentication, multiple chat rooms,
message history, and typing indicators. Use Python Flask-SocketIO for the backend,
SQLite for message persistence, and a responsive HTML/CSS/JS frontend.
```

### 6. Weather Dashboard
```
Build a weather dashboard that shows current weather, 5-day forecast, humidity,
wind speed, and UV index for any city. Include a search bar with auto-complete,
beautiful weather icons, and responsive cards. Use Python Flask backend with
OpenWeatherMap API integration and a modern HTML/CSS/JS frontend.
```

---

## 🔴 Advanced Projects

### 7. REST API with Authentication
```
Build a complete REST API for a blog platform with JWT authentication,
user registration and login, CRUD operations for posts and comments,
role-based access control (admin vs regular user), pagination, and
rate limiting. Use Python FastAPI with SQLite.
```

### 8. E-Commerce Product Catalog
```
Create a product catalog system with categories, search and filtering,
product detail pages, shopping cart functionality, and an admin panel
to manage inventory. Use Python Flask, SQLite, and server-rendered
HTML templates with Jinja2.
```

### 9. Markdown Note-Taking App
```
Build a markdown note-taking application with a split-view editor
(raw markdown on left, live preview on right), folder organization,
full-text search, dark/light theme toggle, and export to PDF.
Use Node.js Express backend and vanilla JavaScript frontend.
```

---

## 💡 Tips for Best Results

1. **Be specific about the tech stack** — mention the language, framework, and database you want.
2. **List features explicitly** — the more detail, the better the generated code.
3. **Keep it to one application** — don't ask for multiple unrelated projects in one prompt.
4. **Mention the UI style** — "dark theme", "modern", "minimal", "responsive" help guide the design.
